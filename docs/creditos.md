# Créditos e fontes

Dados operacionais: Ministério das Cidades, SINISA 2025, ano de referência 2024; planilhas municipais retificadas. Dados domiciliares, cadastro e malha: IBGE, Censo 2022 e APIs oficiais. Os arquivos de proveniência contêm URLs e hashes. Não se atribui ao projeto a autoria dos dados oficiais.

Interface inspirada na navegação territorial de https://github.com/bpinheiroms/open-apuracao-brazil. A implementação desta entrega foi escrita para Água para Todos; não foram copiados os arquivos de simulação, imagens, dados eleitorais ou malhas daquele projeto.

Bibliotecas de interface: Preact (MIT), Leaflet (BSD-2-Clause), Plotly.js (MIT). Suas licenças estão em `docs/licencas/`. Ferramentas de desenvolvimento e científicas mantêm suas próprias licenças. Consulte também os metadados dos pacotes instalados para dependências transitivas.

O uso de dados oficiais deve manter fonte, referência temporal e ressalvas metodológicas. Esta entrega não declara uma licença adicional sobre os dados de terceiros. Não foi feita auditoria jurídica específica de todas as condições de redistribuição.
